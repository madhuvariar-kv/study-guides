# Study Guides

Interactive, animated self-study guides (Kerala SCERT syllabus).

Start at `index.html`: **class → subject → chapter**. Every page is a single self-contained HTML file.

| Class | Subject | Chapters |
|---|---|---|
| Class 9 | Mathematics | 1. Pairs of Equations, 2. New Numbers, 3. Parallel Lines, 4. Multiplication Identities, 5. Irrational Numbers, 6. Similar Triangles, 7. Negative Numbers, 8. Measures of Circles, 9. Real Numbers, 10. Polynomials |

This folder is generated by `_build_workspace/build_site.py`; edit chapter sources there and re-run it.
