1. Three ways to crack a two-unknown puzzle

🧠 Mental

Compare the two facts and ask what the difference pays for. Table + 1 chair = ₹11000, table + 4 chairs = ₹14000 ⇒ 3 chairs cost ₹3000 ⇒ chair ₹1000.

Page 5

✏️ One letter

Name one unknown x and write the other with it: table = 11000 − x. Then one equation: (11000 − x) + 4x = 14000 ⇒ x = 1000.

✏️✏️ Two letters

Each fact becomes an equation: x + y = 11000, 4x + y = 14000. Then combine them – by substitution or by elimination – until one letter is left.

2. The methods

Substitution

Use one equation to say what one letter equals, and put that in the other.

y = 2(x + 1), y + 1 = 3x 2(x + 1) + 1 = 3x ⇒ x = 3, y = 8

3. Three kinds of pairs

One solution

x + y = 10, x − y = 2 ⇒ x = 6, y = 4. The usual case: two different facts.

Same information

x + y = 7, 4x + 4y = 28: the second is just 4 times the first. Many answers – the prices cannot be found separately.

Impossible data

x + y = 5, y − x = 5.5 for lengths: x would be negative. Or x + y = 5, 2x + 2y = 12: the facts contradict each other.

The little graphs show each equation as a line (beyond the textbook): crossing lines = one solution, the same line = many, parallel lines = none.

⚠️ Common mistakes
  • Sign errors when subtracting: (12x + 9y) − (12x − 8y) = 17y, not y. Subtracting −8y adds 8y.
  • Multiplying only one side: 2 × (3x + 4y = 66) is 6x + 8y = 132 – the 66 must be doubled too.
  • Forgetting the second unknown: after y = 12, put it back to find x.
  • Not checking: substitute your answer in both original equations.
  • Ignoring sense: a negative length, half a person or a fraction of a coin means the data or the working is wrong.
  • Mixing up who is bigger: "4 more girls than boys" is g = b + 4, not b = g + 4.
