5.
For any polynomial p(x), p(0) equals .
(1)
Answer: the constant term

With x = 0 every term containing x becomes 0, and only the number without x is left. E.g. p(x) = 2x2 − 5x + 3 gives p(0) = 3.

Marks: 1 mark.

9.
p(x) = 2x2 − 3x + 1. Find p(0), p(1), p(−1) and p(2).
(2)
🎬 Step by step
Answer: 1, 0, 6, 3

p(0) = 0 − 0 + 1 = 1. p(1) = 2 − 3 + 1 = 0. p(−1) = 2 × 1 − 3 × (−1) + 1 = 2 + 3 + 1 = 6. p(2) = 2 × 4 − 6 + 1 = 3.

Marks: ½ mark for each value.

10.
A rectangle has sides 4 cm and 6 cm. Every side is increased by x cm. Write the perimeter p(x) of the new rectangle and find p(2½).
(2)
🎬 Step by step
Answer: p(x) = 4x + 20;  p(2½) = 30 cm

The old perimeter is 2 × (6 + 4) = 20 cm. Each of the four sides grows by x, so 4x is added: p(x) = 4x + 20. (Or 2((6 + x) + (4 + x)) = 4x + 20.) p(2½) = 4 × 2½ + 20 = 10 + 20 = 30 cm.

Marks: 1 mark for p(x), 1 mark for p(2½).

11.
Squares of side x cm are drawn. Is each relation a polynomial? Give the reason. (i) The side and the length of the diagonal. (ii) The side and the area of the square drawn on the diagonal.
(2)
🎬 Step by step
Answer: (i) √2 x – polynomial;  (ii) 2x2 – polynomial

(i) By Pythagoras the diagonal is √(x2 + x2) = √(2x2) = √2 x. The only operation on x is multiplying by the fixed number √2, so it is a polynomial (degree 1). (ii) The area is (√2 x)2 = 2x2, a polynomial of degree 2.

Marks: 1 mark each (½ for the expression, ½ for the reason).

12.
Show that (x + √x)(x − √x) is a polynomial, and find its degree.
(2)
🎬 Step by step
Answer: x2 − x, degree 2

(x + √x)(x − √x) = x2 − x√x + √x·x − (√x)2 = x2 − x. The square roots cancel, leaving only x2 and x: a polynomial of degree 2 (for x ≥ 0, where √x exists).

Marks: 1 mark for multiplying out, 1 mark for x2 − x and degree 2.

13.
p(x) = x3 + 2x2 + 5x + 3. Find p(1) and p(10). What pattern do you see?
(2)
🎬 Step by step
Answer: p(1) = 11, p(10) = 1253

p(1) = 1 + 2 + 5 + 3 = 11, the sum of the coefficients. p(10) = 1000 + 200 + 50 + 3 = 1253: the coefficients 1, 2, 5, 3 become the digits, because each power of 10 is a place value.

Marks: ½ mark for each value, 1 mark for the pattern.

SECTION C4 × 3 = 12 marks
14.
A rectangle has sides 5 cm and 3 cm. Every side is increased by x cm. (i) Write the area a(x) of the new rectangle as a polynomial. (ii) Find a(1) and a(2). (iii) Draw the area model.
(3)
🎬 Step by step
Answer: a(x) = x2 + 8x + 15;  a(1) = 24, a(2) = 35

(i) The new sides are x + 5 and x + 3: a(x) = (x + 5)(x + 3) = x2 + 3x + 5x + 15 = x2 + 8x + 15. (ii) a(1) = 1 + 8 + 15 = 24 (check 6 × 4); a(2) = 4 + 16 + 15 = 35 (check 7 × 5). (iii) The model has four parts: 15, 5x, 3x and x2.

Marks: 1 mark for a(x), ½ mark each for a(1), a(2), 1 mark for the diagram.

Review: Page 6 · a(x) = x² + 5x + 6

15.
Rectangles are made with a loop of string 60 cm long. One side is x cm. (i) Write the area a(x). (ii) Show that a(10) = a(20) and explain why. (iii) When do two different values of x give the same area?
(3)
🎬 Step by step
Answer: a(x) = 30x − x2;  a(10) = a(20) = 200;  x + y = 30

(i) Two sides together make half the perimeter, 30 cm, so the other side is 30 − x: a(x) = x(30 − x) = 30x − x2. (ii) a(10) = 10 × 20 = 200 and a(20) = 20 × 10 = 200: a side of 10 makes the other side 20 and vice versa – it is the same rectangle turned around. (iii) Values x and y give the same area when x + y = 30.

Marks: 1 mark for a(x), 1 mark for the values with the reason, 1 mark for x + y = 30.

Review: Page 7 · Exercise 1, Q3

16.
For p(x) = ax3 + bx2 + cx + d find p(0), p(1) and p(−1). Use them to find p(0), p(1), p(−1) for p(x) = 2x3 − x2 + 4x − 5.
(3)
🎬 Step by step
Answer: d, a + b + c + d, −a + b − c + d;  −5, 0, −12

p(0) = d; p(1) = a + b + c + d; p(−1) = a(−1) + b(1) + c(−1) + d = −a + b − c + d. Here a = 2, b = −1, c = 4, d = −5: p(0) = −5; p(1) = 2 − 1 + 4 − 5 = 0; p(−1) = −2 − 1 − 4 − 5 = −12.

Marks: 1½ marks for the general values, 1½ marks for the three numbers.

17.
Which of these are polynomials? Give reasons. (i) 3x2 − √5 x + ½ (ii) x2 + 2/x (iii) √(x2 + 1) (iv) (√x + 1)2
(3)
🎬 Step by step
Answer: Only (i) is a polynomial

(i) Yes, degree 2: √5 and ½ are fixed numbers. (ii) No: 2/x divides by the changing number (reciprocal). (iii) No: the square root of an expression containing x. (iv) No: (√x + 1)2 = x + 2√x + 1 and the √x does not go away.

Marks: ¾ mark each (decision + reason).

SECTION D2 × 5 = 10 marks
18.
From a card 12 cm long and 8 cm wide, squares of side x cm are cut from the four corners and the sides are folded up to make an open box. (i) Write the length, width and height of the box. (ii) Write its volume v(x) as a polynomial. (iii) What is its degree? (iv) Find v(1) and v(2). (v) Which values can x take?
(5)
🎬 Step by step
Answer: 12 − 2x, 8 − 2x, x;  v(x) = 4x3 − 40x2 + 96x;  degree 3;  v(1) = 60, v(2) = 64;  0 < x < 4

(i) Each end loses x twice: length 12 − 2x, width 8 − 2x, height x. (ii) (12 − 2x)(8 − 2x) = 96 − 24x − 16x + 4x2 = 4x2 − 40x + 96, so v(x) = x(4x2 − 40x + 96) = 4x3 − 40x2 + 96x. (iii) Degree 3. (iv) v(1) = 4 − 40 + 96 = 60 (check 10 × 6 × 1); v(2) = 32 − 160 + 192 = 64 (check 8 × 4 × 2). (v) The width 8 − 2x must be positive, so 0 < x < 4.

Marks: (i) 1, (ii) 2, (iii) ½, (iv) 1, (v) ½ mark.

Review: Page 7 · Exercise 1, Q2 (the box) · Page 12 · Box from a card

19.
A rectangular block has edges 1 cm, 2 cm and 3 cm. Every edge is increased by x cm. (i) Find the volume v(x) by multiplying out. (ii) Find v(1) in two ways. (iii) Write the total surface area s(x) as a polynomial. (iv) Find s(1).
(5)
🎬 Step by step
Answer: v(x) = x3 + 6x2 + 11x + 6;  v(1) = 24;  s(x) = 6x2 + 24x + 22;  s(1) = 52

(i) (x + 2)(x + 3) = x2 + 5x + 6; (x + 1)(x2 + 5x + 6) = x3 + 5x2 + 6x + x2 + 5x + 6 = x3 + 6x2 + 11x + 6. (ii) Edges 2, 3, 4: 2 × 3 × 4 = 24; and 1 + 6 + 11 + 6 = 24. (iii) s(x) = 2[(x + 1)(x + 2) + (x + 2)(x + 3) + (x + 1)(x + 3)] = 2[(x2 + 3x + 2) + (x2 + 5x + 6) + (x2 + 4x + 3)] = 2(3x2 + 12x + 11) = 6x2 + 24x + 22. (iv) s(1) = 6 + 24 + 22 = 52 (check 2(2·3 + 3·4 + 2·4) = 2 × 26 = 52).

Marks: (i) 2, (ii) 1, (iii) 1½, (iv) ½ mark.
