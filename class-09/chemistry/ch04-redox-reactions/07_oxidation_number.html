Oxidation Number and How to Find It ഓക്സിഡേഷൻ നമ്പർ

Valency tells you how many electrons an atom gives, takes or shares – but not which way they go. The oxidation number adds the missing sign: +1 for sodium in NaCl, −1 for chlorine. On this page you meet Table 4.6 again, learn the two key ideas of the book, use Table 4.7, and then find the oxidation number of nitrogen in HNO₃, of chromium in K₂Cr₂O₇ and of manganese in KMnO₄ – step by step, and with a calculator lab that shows why the charges must add up to zero.

📖 What you need (pages 2, 5 and 6 of this guide)
  • Valency, ions and charges; electronegativity – the more electronegative atom pulls the shared pair (page 2).
  • Oxidation = loss of electrons; reduction = gain of electrons (page 5).
  • Oxidising agent is reduced; reducing agent is oxidised (page 6).

1. Valency is not enough – Table 4.6

മൂലകങ്ങളുടെ സംയോജകത (valency) യെക്കുറിച്ച് നിങ്ങൾ മനസ്സിലാക്കിയിട്ടുണ്ടല്ലോ? പട്ടിക 4.6 വിലയിരുത്തുക. You already know the valency സംയോജകത of elements. Evaluate Table 4.6. Then press the two buttons to add what valency does not tell you.

Sodium and fluorine both have valency 1 – yet one loses an electron and the other gains one. Valency alone cannot tell them apart.

മൂലകത്തിന്റെ സംയോജകതയിൽ നിന്നും രാസപ്രവർത്തനത്തിൽ മൂലകങ്ങൾ ഇലക്ട്രോണുകൾ നേടുകയാണോ നഷ്ടപ്പെടുകയാണോ എന്നറിയാൻ കഴിയുമോ? ഇതു വ്യക്തമാക്കുന്നതിനായി ഓക്സിഡേഷൻ നമ്പർ ഉപയോഗിക്കുന്നു. ഇലക്ട്രോണുകൾ നഷ്ടപ്പെടുമ്പോൾ പോസിറ്റീവ് അയോണും ഇലക്ട്രോണുകൾ നേടുമ്പോൾ നെഗറ്റീവ് അയോണും ഉണ്ടാകുമല്ലോ. Can we tell from the valency of an element whether it gains or loses electrons in a reaction? No. To make this clear we use the oxidation number ഓക്സിഡേഷൻ നമ്പർ. When electrons are lost a positive ion forms, and when electrons are gained a negative ion forms – so the oxidation number carries a sign.

⭐ Key idea (textbook page 79)
ഒരു സംയുക്തത്തിലെ എല്ലാ രാസബന്ധനങ്ങളും അയോണിക (Ionic bond) മായി പരിഗണിച്ചാൽ അതിലെ ഓരോ ആറ്റത്തിലും രൂപം കൊള്ളുന്ന ചാർജിനെ ആ ആറ്റത്തിന്റെ ഓക്സിഡേഷൻ നമ്പർ അഥവാ ഓക്സീകരണാവസ്ഥ എന്ന് പറയുന്നു.

If all the chemical bonds in a compound are taken to be ionic, the charge that would form on each atom is called the oxidation number or oxidation state ഓക്സിഡേഷൻ നമ്പർ · ഓക്സീകരണാവസ്ഥ of that atom.

2. In ionic compounds: NaCl and MgO

സോഡിയം അയോണും (Na⁺) ക്ലോറൈഡ് അയോണും (Cl⁻) ചേർന്നതാണ് NaCl. അയോണികസംയുക്തങ്ങളിൽ ഇതുപോലെയുള്ള അയോണുകളുടെ ചാർജ് തന്നെയാണ് ഓക്സിഡേഷൻ നമ്പർ. അതുകൊണ്ട് സോഡിയം ക്ലോറൈഡിൽ സോഡിയത്തിന്റെ ഓക്സിഡേഷൻ നമ്പർ +1-ഉം ക്ലോറിന്റേത് −1-ഉം ആണ്. NaCl is made of sodium ions (Na⁺) and chloride ions (Cl⁻). In ionic compounds the charge of the ion itself is the oxidation number. So in sodium chloride the oxidation number of sodium is +1 and that of chlorine is −1. Like the book, we write it above the symbol:

  Na⁺ Cl⁻

Q (page 79). മഗ്നീഷ്യം ഓക്സൈഡിൽ (MgO) മഗ്നീഷ്യത്തിന്റെ ഓക്സിഡേഷൻ നമ്പർ +2, ഓക്സിജന്റെ ഓക്സിഡേഷൻ നമ്പർ −2 എന്നിങ്ങനെയാണ്. ഇതിൽനിന്നും നിങ്ങൾ എന്താണ് മനസ്സിലാക്കുന്നത്? In magnesium oxide (MgO) the oxidation number of magnesium is +2 and that of oxygen is −2. What do you understand from this?

• MgO is made of Mg²⁺ and O²⁻ ions: magnesium lost 2 electrons (2, 8, 2 → 2, 8) and oxygen gained 2 (2, 6 → 2, 8). In an ionic compound the oxidation number is the charge of the ion: Mg +2, O −2.
• The sign shows the direction: + means electrons lost, − means electrons gained. (The valency of both is just 2.)
• The oxidation numbers add up to zero: (+2) + (−2) = 0, because the compound as a whole has no charge.

3. In covalent compounds: imagine the bond is ionic (HF)

ഇലക്ട്രോണുകൾ പങ്ക് വയ്ക്കപ്പെട്ടാണ് സഹസംയോജക സംയുക്തങ്ങൾ (Covalent compounds) ഉണ്ടാകുന്നത്. ഇവയിൽ, ഇലക്ട്രോനെഗറ്റിവിറ്റി ഏറ്റവും കൂടിയ ആറ്റത്തിലേക്ക്, പങ്കുവയ്ക്കപ്പെട്ട ഇലക്ട്രോണുകൾ സ്ഥാനമാറ്റം ചെയ്യപ്പെടുന്നുവെന്ന് സങ്കൽപ്പിച്ചാണ് ഇവയിലെ ആറ്റങ്ങളുടെ ഓക്സിഡേഷൻ നമ്പർ നിർണ്ണയിക്കുന്നത്. Covalent compounds form by sharing electrons, so there are no real ions. To find the oxidation numbers we imagine that the shared electrons have moved completely to the atom with the higher electronegativity.

ഉദാഹരണത്തിന് സഹസംയോജകസംയുക്തമായ HF ൽ ഇലക്ട്രോനെഗറ്റിവിറ്റി കൂടിയ F ലേയ്ക്ക് ഇലക്ട്രോണുകൾ സ്ഥാനമാറ്റം ചെയ്യപ്പെടുന്നുവെന്ന് സങ്കൽപ്പിച്ച് F ന്റെ ഓക്സിഡേഷൻ നമ്പർ −1 ആയി പരിഗണിക്കുന്നു. ഇലക്ട്രോൺ നഷ്ടപ്പെട്ടതായി സങ്കൽപ്പിച്ച് H ന്റെ ഓക്സിഡേഷൻ നമ്പർ +1 ആയി പരിഗണിച്ചിരിക്കുന്നു. For example, in the covalent compound HF we imagine the shared electrons have moved to the more electronegative F (3.98 against 2.20 for H). So F is taken as −1, and H, imagined to have lost its electron, as +1. Try it:

Electronegativity values (Pauling, Chapter 3): H 2.20 · C 2.55 · Cl 3.16 · O 3.44 · F 3.98. Nothing really moves in the molecule – this is only the bookkeeping rule for oxidation numbers.

⭐ Key ideas (textbook page 80)
● ഒരു സംയുക്തത്തിലെ ഘടക ആറ്റങ്ങളുടെ ഓക്സിഡേഷൻ നമ്പറുകളുടെ ആകെത്തുക പൂജ്യമാണ്.
● മൂലകതന്മാത്രകളിൽ ആറ്റങ്ങൾ ഇലക്ട്രോണുകളെ തുല്യമായി പങ്കുവയ്ക്കുന്നതിനാൽ മൂലകാവസ്ഥയിൽ ഓക്സിഡേഷൻ നമ്പർ പൂജ്യമായി പരിഗണിക്കുന്നു.
  • The sum of the oxidation numbers of the constituent atoms of a compound is zero.
  • In molecules of elements the atoms share electrons equally, so in the elemental state മൂലകാവസ്ഥ the oxidation number is taken as zero (Na, Mg, H₂, Cl₂, O₂, N₂ …).

Table 4.7 പട്ടിക 4.7

ഓക്സിഡേഷൻ നമ്പർ കണക്കാക്കുന്ന രീതി. ചില മൂലകങ്ങളുടെ വിവിധ സംയുക്തങ്ങളിലെ സാധാരണ ഓക്സിഡേഷൻ നമ്പർ പട്ടിക 4.7-ൽ നൽകിയിരിക്കുന്നു. സംയുക്തങ്ങളിൽ ഓക്സിഡേഷൻ നമ്പർ അറിയാത്ത മൂലകങ്ങളുടെ ഓക്സിഡേഷൻ നമ്പർ കണ്ടെത്താമോ? നമുക്കു പരിശോധിക്കാം.

The method of calculating oxidation numbers. Table 4.7 gives the usual oxidation numbers of some elements in their compounds. Can we find the oxidation number of an element that is not in the table? Let us check – with three rules:

📋 Rules card
  1. Take the known values from Table 4.7 (H +1, O −2, Na/K +1, Ca +2, Al +3, F/Cl/Br/I −1).
  2. Call the unknown one x. Multiply each value by the number of atoms of that element (the subscript).
  3. The sum is zero for a compound → solve for x. Write the answer with the sign first: +5, not 5+.

In the elemental state the oxidation number is 0. Metals in compounds are always positive.

5. Worked example: nitrogen in nitric acid, HNO₃

HNO₃ ൽ നൈട്രജന്റെ ഓക്സിഡേഷൻ നമ്പർ കണ്ടെത്തുന്നത് എങ്ങിനെയെന്ന് നോക്കാം. പട്ടിക 4.7 പ്രകാരം, ഹൈഡ്രജന്റെ ഓക്സിഡേഷൻ നമ്പർ = +1, ഓക്സിജന്റെ ഓക്സിഡേഷൻ നമ്പർ = −2. നൈട്രജന്റെ ഓക്സിഡേഷൻ നമ്പർ x ആയി സങ്കൽപ്പിക്കാം. ഒരു സംയുക്തത്തിലെ ആറ്റങ്ങളുടെ ഓക്സിഡേഷൻ നമ്പറുകളുടെ തുക പൂജ്യമാണല്ലോ. Let us see how to find the oxidation number of nitrogen in HNO₃. From Table 4.7, hydrogen = +1 and oxygen = −2. Take the oxidation number of nitrogen as x. The sum of the oxidation numbers of the atoms in a compound is zero, so in the HNO₃ molecule:

🎬 Step by step: HNO₃
(+1) + (1 × x) + (−2 × 3)=0+1 + x + (−6)=0x − 5=0x=+5

Oxidation number of nitrogen in HNO₃ = +5. Check: (+1) + (+5) + 3 × (−2) = +6 − 6 = 0 ✓

Q (page 80). HNO₂, NO₂ എന്നിവയിൽ നൈട്രജന്റെ ഓക്സിഡേഷൻ നമ്പർ കണ്ടെത്തുക. Find the oxidation number of nitrogen in HNO₂ and NO₂.

HNO₂ (nitrous acid): (+1) + (1 × x) + (−2 × 2) = 0 → +1 + x − 4 = 0 → x − 3 = 0 → x = +3.
NO₂ (nitrogen dioxide): (1 × x) + (−2 × 2) = 0 → x − 4 = 0 → x = +4.
So nitrogen can have different oxidation numbers: +5 in HNO₃, +3 in HNO₂, +4 in NO₂ (and −3 in NH₃ – try it in the calculator below).

6. Worked example: chromium in potassium dichromate, K₂Cr₂O₇

പൊട്ടാസ്യം ഡൈക്രോമേറ്റിൽ (K₂Cr₂O₇) ക്രോമിയത്തിന്റെ (Cr) ഓക്സിഡേഷൻ നമ്പർ കണ്ടെത്താം. ക്രോമിയത്തിന്റെ ഓക്സിഡേഷൻ നമ്പർ x ആണെന്ന് സങ്കൽപ്പിച്ചാൽ Let us find the oxidation number of chromium (Cr) in potassium dichromate, K₂Cr₂O₇ (an orange compound used as an oxidising agent in the lab). Take the oxidation number of chromium as x. This time there are 2 K atoms, 2 Cr atoms and 7 O atoms – multiply!

🎬 Step by step: K₂Cr₂O₇
(+1 × 2) + (2 × x) + (−2 × 7)=02 + (2x) + (−14)=02x − 12=02x=+12x=+12/2 = +6

Oxidation number of chromium in K₂Cr₂O₇ = +6. Check: 2 × (+1) + 2 × (+6) + 7 × (−2) = 2 + 12 − 14 = 0 ✓

Q (page 81). Cr₂O₃ ൽ ക്രോമിയത്തിന്റെ ഓക്സിഡേഷൻ നമ്പർ കണ്ടെത്തൂ. Find the oxidation number of chromium in Cr₂O₃.

(2 × x) + (−2 × 3) = 0 → 2x − 6 = 0 → 2x = +6 → x = +6/2 = +3. Chromium is +3 in Cr₂O₃ (a green oxide) but +6 in K₂Cr₂O₇.

🧭 Summary
  • Oxidation number (oxidation state): the charge an atom would have if all the bonds in the compound were ionic.
  • Ionic compounds: the oxidation number is the charge of the ion (NaCl: Na +1, Cl −1; MgO: Mg +2, O −2).
  • Covalent compounds: the shared electrons are taken to the more electronegative atom (HF: F −1, H +1).
  • The sum in a compound is 0; in the elemental state it is 0.
  • Method: Table 4.7 values × number of atoms + (number × x) = 0. HNO₃ N +5 · HNO₂ +3 · NO₂ +4 · K₂Cr₂O₇ Cr +6 · Cr₂O₃ +3 · MnO₂ +4 · Mn₂O₇ +7 · KMnO₄ +7.
