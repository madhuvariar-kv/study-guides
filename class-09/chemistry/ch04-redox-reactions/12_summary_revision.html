2. The key boxes of the textbook

1Conservation of mass (p. 71)മാസ് സംരക്ഷണനിയമം

In a chemical reaction the total mass of the reactants equals the total mass of the products. – page 3

2Balancing (p. 74)രാസസമവാക്യ സമീകരണം · സമീകൃത രാസസമവാക്യം

Making the number of each kind of atom equal on both sides is balancing; the result is a balanced chemical equation. – page 4

3Oxidation (p. 76)ഓക്സീകരണം

The process in which electrons are lost in a chemical reaction: Na → Na+ + e−. – page 5

4Reduction (p. 76)നിരോക്സീകരണം

The process in which electrons are gained: Cl + e− → Cl−. – page 5

5Oxidising agent (p. 77)ഓക്സീകാരി

The substance that helps oxidation; it is itself reduced in the reaction (Cl2 in 2Na + Cl2 → 2NaCl). – page 6

6Reducing agent (p. 78)നിരോക്സീകാരി

The substance that helps reduction; it is itself oxidised (Na in 2Na + Cl2 → 2NaCl). – page 6

7Oxidation number (p. 79)ഓക്സിഡേഷൻ നമ്പർ · ഓക്സീകരണാവസ്ഥ

If all the bonds in a compound are taken as ionic, the charge on each atom is its oxidation number (oxidation state). – page 7

8Sum is zero (p. 80)മൂലകാവസ്ഥ

The sum of the oxidation numbers of the atoms in a compound is zero; in the elemental state the oxidation number is zero. – page 7

9Up and down (p. 82)ഓക്സീകരണം · നിരോക്സീകരണം

A reaction in which the oxidation number increases is oxidation; one in which it decreases is reduction. – page 8

10Redox reactions (p. 83)റിഡോക്സ് പ്രവർത്തനങ്ങൾ

Oxidation and reduction take place at the same time. In a redox reaction the oxidising agent is reduced and the reducing agent is oxidised. – page 8

Balancing an equation രാസസമവാക്യ സമീകരണം

  1. Write the correct formulae of the reactants and products (H2, O2, Cl2, N2 are molecules).
  2. Count each kind of atom on both sides (a table helps: Tables 4.3–4.5).
  3. Change only the coefficients (the numbers in front) – never the subscripts.
  4. Start with an atom that is in only one substance on each side; leave free elements such as O2 or H2 to the end.
  5. Check every atom again: 4Al + 3O2 → 2Al2O3 (Al 4 = 4, O 6 = 6).

In an equation, ↑ means a gas is given off and ↓ a precipitate (അവക്ഷിപ്തം) forms; (s) solid, (l) liquid, (g) gas, (aq) in water.

Oxidation and reduction ഓക്സീകരണം · നിരോക്സീകരണം

LOSS = OXIDATIONelectrons lost · oxidation number goes up
Na → Na+ + e− · Al → Al3+ + 3e− · I− → I + e−
GAIN = REDUCTIONelectrons gained · oxidation number goes down
Cl + e− → Cl− · O + 2e− → O2− · Cu2+ + 2e− → Cu

Memory aid: “Loss Oxidation, Gain Reduction” – in English it is often remembered as OIL RIG: Oxidation Is Loss, Reduction Is Gain (of electrons). Metals are generally oxidised; non-metals generally reduced.

Oxidation numbers ഓക്സിഡേഷൻ നമ്പർ

  1. An element in the elemental state (Na, Fe, H2, O2, Cl2, P4) → 0.
  2. In an ionic compound → the charge of the ion (MgO: Mg +2, O −2).
  3. In a covalent compound the shared electrons are counted with the more electronegative atom (HF: F −1, H +1).
  4. Use Table 4.7: H, Na, K +1 · Ca, Mg +2 · Al +3 · F, Cl, Br, I −1 · O −2.
  5. The sum in a compound is 0: write x for the unknown and multiply by the number of atoms – HNO3: (+1) + x + 3(−2) = 0 → x = +5.

Is it a redox reaction? റിഡോക്സ് പ്രവർത്തനങ്ങൾ

  1. Write the oxidation number above every atom on both sides.
  2. Find the element whose number goes up (oxidised) and the one whose number goes down (reduced).
  3. Both found → redox. The reactant containing the oxidised element is the reducing agent; the one containing the reduced element is the oxidising agent.
  4. No change at all (NaOH + HCl → NaCl + H2O; CaCO3 + 2HCl → CaCl2 + H2O + CO2) → not redox.

Redox in daily life: respiration (ശ്വസനം), burning of fuels (ജ്വലനം), decomposition of organic matter in oxygen (വിഘടനം), rusting and the oxide layer on metals (ഓക്സൈഡ് ആവരണം), and electricity from electrochemical cells (രാസവൈദ്യുത സെല്ലുകൾ).

⚠️ Common mistakes
  • Changing subscripts to balance (H2O → H2O2). That makes a different substance – change only the coefficients.
  • Saying mass is lost when wood burns. The gases (CO2, water vapour) escape; the total mass is conserved.
  • Mixing up oxidation and reduction. Loss of electrons = oxidation; gain = reduction.
  • Saying the oxidising agent is oxidised. It is reduced; the reducing agent is oxidised.
  • Forgetting that free elements are 0. Na, Cl2, O2, H2 all have oxidation number 0.
  • Forgetting to multiply by the number of atoms. K2Cr2O7: 2 × (+1) and 7 × (−2), and 2x for the two chromium atoms.
  • Calling every reaction redox. Check for a change in oxidation number – neutralisation and CaCO3 + HCl are not redox.
  • Writing the sign after the number (5+, 2−) for an oxidation number. Write +5, −2 (charges of ions are written 2+, 2−).
