Oxidation Number and Redox Reactions ഓക്സിഡേഷൻ നമ്പറും ഓക്സീകരണ നിരോക്സീകരണ പ്രവർത്തനങ്ങളും

Now the oxidation number becomes a detective's tool. Write it above every symbol on both sides of an equation and compare: if it goes up, that atom was oxidised; if it goes down, it was reduced. You will fill Tables 4.8 and 4.9, analyse Mg + 2HCl, discover that oxidation and reduction always happen together – redox reactions – and find them in breathing, rusting, cooking and your torch battery.

📖 What you need (pages 5–7 of this guide)
  • Oxidation = loss of electrons; reduction = gain of electrons (page 5).
  • The oxidising agent is reduced; the reducing agent is oxidised (page 6).
  • Oxidation numbers: Table 4.7, sum zero in a compound, 0 in the elemental state (page 7).

1. Sodium chloride – write the oxidation numbers above the symbols

സോഡിയം ക്ലോറൈഡ് (NaCl) രൂപീകരണത്തിന്റെ രാസസമവാക്യം വിലയിരുത്തൂ. Evaluate the chemical equation രാസസമവാക്യം for the formation of sodium chloride (NaCl):

2Na + Cl2 → 2NaCl

സോഡിയം ക്ലോറൈഡ് രൂപീകരണത്തിൽ സോഡിയം ഒരു ഇലക്ട്രോൺ നഷ്ടപ്പെട്ട് ഒരു പോസിറ്റീവ് ചാർജും ക്ലോറിൻ ഒരു ഇലക്ട്രോൺ സ്വീകരിച്ച് ഒരു നെഗറ്റീവ് ചാർജും നേടുന്നു. അതിനാൽ സോഡിയത്തിന്റെ ഓക്സിഡേഷൻ നമ്പർ +1, ക്ലോറിന്റെ ഓക്സിഡേഷൻ നമ്പർ −1 എന്നിങ്ങനെയാണല്ലോ. In forming sodium chloride, sodium loses one electron and gets one positive charge, and chlorine accepts one electron and gets one negative charge. So in NaCl the oxidation number of sodium is +1 and that of chlorine −1.

Q (page 81). മൂലകാവസ്ഥയിൽ സോഡിയത്തിന്റെയും ക്ലോറിന്റെയും ഓക്സിഡേഷൻ നമ്പർ എത്രയാണ്? What is the oxidation number of sodium and of chlorine in the elemental state?

0 for both. Sodium metal (Na) and chlorine gas (Cl₂) are elements in the free state മൂലകാവസ്ഥ; in Cl₂ the two atoms share their pair equally, so nothing is gained or lost.

⭐ Key idea (textbook page 82)
ഓക്സിഡേഷൻ നമ്പർ കൂടുന്ന പ്രവർത്തനം ഓക്സീകരണവും ഓക്സിഡേഷൻ നമ്പർ കുറയുന്ന പ്രവർത്തനം നിരോക്സീകരണവുമാണ്.

A change in which the oxidation number increases is oxidation ഓക്സീകരണം; a change in which the oxidation number decreases is reduction നിരോക്സീകരണം.

🔗 Why this fits page 5

Losing an electron (oxidation) makes an atom more positive, so its oxidation number goes up (Na 0 → +1). Gaining an electron (reduction) makes it more negative, so the number goes down (Cl 0 → −1). Memory aid: "up = oxidation, down = reduction".

2. Who is oxidised? Who is the oxidising agent? (page 82)

Q. സോഡിയം ക്ലോറൈഡ് രൂപീകരണത്തിൽ ഓക്സീകരണം സംഭവിച്ചത് ഏത് ആറ്റത്തിനാണ്? In the formation of sodium chloride, which atom was oxidised?

Sodium – its oxidation number increased from 0 to +1.

Q. ഈ പ്രവർത്തനത്തിലെ ഓക്സീകാരി ഏത്? എന്തുകൊണ്ട്? Which is the oxidising agent in this reaction? Why?

Chlorine (Cl₂). It takes the electron from sodium and so causes sodium's oxidation number to rise; while doing this, chlorine itself is reduced (0 → −1). An oxidising agent ഓക്സീകാരി is always reduced.

Q. ഈ പ്രവർത്തനത്തിൽ നിരോക്സീകരണം സംഭവിച്ചത് ഏത് ആറ്റത്തിനാണ്? കാരണമെന്ത്? In this reaction, which atom was reduced? What is the reason?

Chlorine – because its oxidation number decreased from 0 to −1 (it gained an electron).

Q. ഇവിടെ നിരോക്സീകാരി ഏത്? Which is the reducing agent here?

Sodium (Na). It gives its electron to chlorine, helping chlorine to be reduced; sodium itself is oxidised. A reducing agent നിരോക്സീകാരി is always oxidised.

4. Magnesium and hydrochloric acid

മറ്റൊരു രാസസമവാക്യം വിലയിരുത്താം. ഓരോ ആറ്റത്തിന്റെയും ഓക്സിഡേഷൻ നമ്പർ രേഖപ്പെടുത്തുക. Let us evaluate another chemical equation. Write the oxidation number of every atom.

Mg + 2HCl → MgCl2 + H2
✍ Write the oxidation numbers above the symbols

ചുവടെ നൽകിയിട്ടുള്ളവ കണ്ടെത്തൂ. Find the following:

✍ Mg + 2HCl → MgCl₂ + H₂
• Magnesium: 0 → +2, increased → oxidation ഓക്സീകരണം.
• Hydrogen: +1 → 0, decreased → reduction (the H⁺ of the acid gains electrons and becomes H₂ gas – the bubbles).
• Chlorine: −1 → −1, no change – chlorine is only a "spectator" here.
• Oxidising agent: HCl (its hydrogen is reduced). Reducing agent: Mg (it is oxidised).

6. Oxidation and reduction together – redox reactions

ഹൈഡ്രജനും ക്ലോറിനും സംയോജിച്ച് ഹൈഡ്രജൻ ക്ലോറൈഡ് ഉണ്ടാകുന്ന രാസപ്രവർത്തനത്തിന്റെ സമവാക്യം നൽകിയിരിക്കുന്നു. The equation for hydrogen and chlorine combining to form hydrogen chloride is given, with the oxidation numbers:

Q (page 83). ഈ പ്രവർത്തനത്തിൽ ഓക്സീകരണം സംഭവിച്ച ആറ്റം ഏതാണ്? Which atom was oxidised in this reaction?

Hydrogen (0 → +1, increased).

Q (page 83). നിരോക്സീകരണം സംഭവിച്ച ആറ്റമോ? And the atom that was reduced?

Chlorine (0 → −1, decreased). Notice: in the same reaction one atom is oxidised and another is reduced – at the same time.
⭐ Key idea (textbook page 83)
ഇവിടെ ഓക്സീകരണവും നിരോക്സീകരണവും ഒരേ സമയം തന്നെയാണ് നടക്കുന്നത്. ഇത്തരം പ്രവർത്തനങ്ങളെ റിഡോക്സ് പ്രവർത്തനങ്ങൾ (Redox reactions) എന്ന് പറയുന്നു. ഒരു റിഡോക്സ് പ്രവർത്തനത്തിൽ ഓക്സീകാരിക്ക് നിരോക്സീകരണവും നിരോക്സീകാരിക്ക് ഓക്സീകരണവും സംഭവിക്കുന്നു.

Here oxidation and reduction take place at the same time. Such reactions are called redox reactions റിഡോക്സ് പ്രവർത്തനങ്ങൾ (reduction + oxidation). In a redox reaction the oxidising agent is reduced and the reducing agent is oxidised.

🤔 Why together?

Electrons cannot just disappear. If one atom loses electrons (oxidation), another atom must take them (reduction). So whenever an oxidation number goes up somewhere, one goes down somewhere else. If no oxidation number changes – as in NaOH + HCl → NaCl + H₂O – the reaction is not a redox reaction. Test this in the detective lab below.

7. Redox reactions in daily life

നിത്യജീവിതത്തിലെ സുപരിചിതമായ ചില റിഡോക്സ് പ്രവർത്തനങ്ങൾ ചുവടെ കൊടുത്തിരിക്കുന്നു. Some familiar redox reactions of daily life (the equations are "go further" – the book only lists the processes):

🫁 Respiration ശ്വസനം

ശ്വസന പ്രക്രിയയിൽ കോശങ്ങളിൽ വച്ച് ഗ്ലൂക്കോസ് തന്മാത്രകൾ വിഘടിച്ച് ഊർജം സ്വതന്ത്രമാക്കപ്പെടുന്ന പ്രവർത്തനം. In respiration, glucose molecules are broken down in the cells and energy is released – the energy you use after a football match.

Carbon 0 → +4 (oxidised); oxygen 0 → −2 (reduced).

🧱 Oxide layers on metals ഓക്സൈഡ് ആവരണം

ലോഹങ്ങളുടെ ഉപരിതലത്തിൽ ഓക്സൈഡ് ആവരണം ഉണ്ടാകുന്ന പ്രവർത്തനം. An oxide layer forms on the surface of metals – rust on iron gates and fishing boats in the salty coastal air.

Iron 0 → +3 (oxidised); oxygen 0 → −2 (reduced). (Real rust also holds water.) On aluminium the oxide layer is thin and tight, and protects the metal.

🔥 Burning of fuels ഇന്ധനങ്ങളുടെ ജ്വലനം

ഇന്ധനങ്ങളുടെ ജ്വലനം. Combustion of fuels – firewood in the kitchen hearth (അടുപ്പ്), LPG, kerosene, petrol. Methane (biogas) burns like this:

Carbon −4 → +4 (oxidised); oxygen 0 → −2 (reduced). Heat and light are given out.

🍂 Decomposition വിഘടനം

ജൈവവസ്തുക്കൾക്ക് ഓക്സിജന്റെ സാന്നിധ്യത്തിൽ നടക്കുന്ന വിഘടനം. Organic matter decomposes in the presence of oxygen – banana leaves and kitchen waste in a compost pit. Microbes oxidise the carbon compounds to carbon dioxide and water, slowly, giving out a little heat (a compost heap feels warm).

🔋 Electricity from cells രാസവൈദ്യുത സെല്ലുകൾ

രാസവൈദ്യുത സെല്ലുകളിലെ വൈദ്യുത ഉൽപാദനം. Electricity is produced in electrochemical cells – the dry cell in your torch, the battery of a mobile phone. In a dry cell the zinc case is oxidised and gives electrons to the wire; manganese dioxide inside takes them (it is reduced).

Zn → Zn2+ + 2e−  (oxidation)

🧭 Summary
  • Write the oxidation numbers above the symbols on both sides: + → .
  • Oxidation number increases → oxidation; decreases → reduction.
  • Oxidation and reduction happen together → redox reactions. The oxidising agent is reduced, the reducing agent is oxidised.
  • H₂ + Cl₂ → 2HCl: H oxidised, Cl reduced; Cl₂ oxidising agent, H₂ reducing agent. Mg + 2HCl: Mg 0 → +2, HCl oxidising agent. C + O₂ → CO₂: C 0 → +4, O 0 → −2.
  • No change in any oxidation number → not redox (NaOH + HCl, CaCO₃ + 2HCl).
