Atomic Number and Mass Number അറ്റോമിക നമ്പറും മാസ് നമ്പറും

Every atom carries two "ID numbers". One tells you which element it is, the other tells you how heavy its nucleus is. On this page you learn to read them from a symbol like 3517Cl, count the protons, electrons and neutrons of any atom, complete the textbook table, and build your own atoms with the atom builder.

📖 What you need (page 7 of this guide)
  • The nucleus ന്യൂക്ലിയസ് holds the protons പ്രോട്ടോൺ (charge +1, mass ≈ 1 u) and the neutrons ന്യൂട്രോൺ (charge 0, mass ≈ 1 u).
  • The electrons ഇലക്ട്രോൺ (charge −1, mass ≈ 0) move in shells around the nucleus.
  • An atom is electrically neutral: its total + charge equals its total − charge. Review: page 7 – Bohr's model & the three particles.

1. The number that decides the element – atomic number (Z)

ഒരു ആറ്റം ഏതു മൂലകത്തിന്റേതാണെന്ന് തീരുമാനിക്കുന്നത് അതിലുള്ള പ്രോട്ടോണുകളുടെ എണ്ണം ആണ്. – The number of protons in an atom decides which element മൂലകം it belongs to. Every atom with 1 proton is hydrogen, every atom with 6 protons is carbon, every atom with 17 protons is chlorine. Change the number of protons and you get a different element.

The total number of protons in an atom is called its atomic number അറ്റോമിക നമ്പർ, written with the letter Z. Because an atom is neutral, it has exactly as many electrons (−1 each) as protons (+1 each).

⭐ Key idea (textbook page 14)

അറ്റോമിക നമ്പർ = പ്രോട്ടോണുകളുടെ എണ്ണം = ഇലക്ട്രോണുകളുടെ എണ്ണം

Atomic number (Z) = number of protons = number of electrons

Question (page 14). ആറ്റത്തിന്റെ ന്യൂക്ലിയസിലെ കണങ്ങൾ ഏതൊക്കെയാണ്? Which particles are present in the nucleus of an atom?

Protons and neutrons. Together they are sometimes called nucleons. The electrons are not in the nucleus – they move in the shells around it.

2. Mass number (A) and the number of neutrons

ഒരാറ്റത്തിലെ പ്രോട്ടോണുകളുടെയും ന്യൂട്രോണുകളുടെയും ആകെ എണ്ണത്തെ മാസ് നമ്പർ എന്ന് പറയുന്നു. – The total number of protons and neutrons in an atom is called its mass number മാസ് നമ്പർ, written with the letter A. Why "mass"? A proton and a neutron each have a mass of about 1 u, while an electron's mass is almost 0. So the mass number is (very nearly) the mass of the atom in u.

Question (page 14). 2 പ്രോട്ടോണുകളും, 2 ന്യൂട്രോണുകളും ഉള്ള ഒരു ആറ്റത്തിന്റെ മാസ് നമ്പർ എത്രയായിരിക്കും? What will be the mass number of an atom that has 2 protons and 2 neutrons?

Mass number = protons + neutrons. Count only the particles in the nucleus.

A = 2 + 2 = 4. Two protons means Z = 2, so this is helium: 42He (helium-4). It also has 2 electrons, but electrons are not counted in the mass number.
🔬 The helium-4 atom
⭐ Key idea (textbook page 14)

മാസ് നമ്പർ = പ്രോട്ടോണുകളുടെ എണ്ണം + ന്യൂട്രോണുകളുടെ എണ്ണം = അറ്റോമിക നമ്പർ + ന്യൂട്രോണുകളുടെ എണ്ണം

ന്യൂട്രോണുകളുടെ എണ്ണം = മാസ് നമ്പർ − പ്രോട്ടോണുകളുടെ എണ്ണം = മാസ് നമ്പർ − അറ്റോമിക നമ്പർ = (A − Z)

Mass number (A) = number of protons + number of neutrons = atomic number + number of neutrons
Number of neutrons = mass number − atomic number = A − Z

A = Z + n ⇔ n = A − Z

3. Writing an atom with its symbol

ഒരു ആറ്റത്തെ പ്രതീകം ഉപയോഗിച്ച് പ്രതിനിധാനം ചെയ്യുമ്പോൾ പ്രതീകത്തിന്റെ ഇടതുവശത്ത് മുകളിലും താഴെയുമായി യഥാക്രമം മാസ് നമ്പറും അറ്റോമിക നമ്പറും എഴുതുന്നു. – When we represent an atom with its symbol പ്രതീകം, we write the mass number on top and the atomic number below, both on the left side of the symbol. Examples from the book: 3517Cl and 4020Ca.

🔎 Reading the symbol

Memory trick: the bigger number (A) sits on top. A can never be smaller than Z, because A = Z + neutrons. (For ordinary hydrogen, 11H, they are equal – it has no neutron.)

4. Worked example – chlorine and calcium (page 15)

Question (page 15). ക്ലോറിൻ, കാൽസ്യം എന്നീ ആറ്റങ്ങളിലെ പ്രോട്ടോണുകൾ, ഇലക്ട്രോണുകൾ, ന്യൂട്രോണുകൾ എന്നിവയുടെ എണ്ണം കണ്ടെത്തുക. Find the number of protons, electrons and neutrons in the chlorine atom 3517Cl and the calcium atom 4020Ca.

Bottom number → protons → electrons. Then neutrons = top − bottom.

🎬 Step by step: protons, electrons and neutrons
3517Cl: protons 17, electrons 17, neutrons 35 − 17 = 18.
4020Ca: protons 20, electrons 20, neutrons 40 − 20 = 20.
Check: protons + neutrons gives back the mass number (17 + 18 = 35, 20 + 20 = 40).

⚠️ Common mistakes
  • Swapping the numbers: in 2311Na the top number (23) is A and the bottom number (11) is Z.
  • Neutrons = A + Z ✗. It is A − Z: for 2311Na, 23 − 11 = 12 neutrons.
  • Counting electrons in the mass number ✗. Only protons and neutrons count.
  • Thinking the neutrons decide the element ✗. Only the number of protons does.

🧭 Summary
  • The number of protons decides the element. Atomic number Z = number of protons = number of electrons.
  • Mass number A = protons + neutrons; neutrons = A − Z.
  • Symbol notation: A on top, Z below, on the left: 3517Cl → 17 p, 17 e, 18 n; 4020Ca → 20 p, 20 e, 20 n.
